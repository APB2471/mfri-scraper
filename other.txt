5. Raspberry Pi OS Deployment Guide
Bash
# 1. Install system dependencies
sudo apt update && sudo apt install -y python3 python3-venv python3-pip

# 2. Create project directory and virtual environment
mkdir -p /home/pi/mfri_scraper
cd /home/pi/mfri_scraper
python3 -m venv venv

# 3. Install lightweight Python libraries inside venv
/home/pi/mfri_scraper/venv/bin/pip install --upgrade pip
/home/pi/mfri_scraper/venv/bin/pip install requests beautifulsoup4

# 4. Secure configuration and make script executable
chmod 600 /home/pi/mfri_scraper/config.json
chmod +x /home/pi/mfri_scraper/mfri_scraper.py
Configure Cron (crontab -e)
Open the user crontab (crontab -e) and add the 10-minute schedule redirecting all stdout/stderr to cron.log:

Code snippet
*/10 * * * * /home/pi/mfri_scraper/venv/bin/python /home/pi/mfri_scraper/mfri_scraper.py >> /home/pi/mfri_scraper/cron.log 2>&1
